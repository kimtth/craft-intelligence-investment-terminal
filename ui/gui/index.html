        Indicator formulas & limits
        SMA20 / SMA50: arithmetic mean of the last 20 / 50 provider closes, including the current bar; first available at bar 20 / 50. RSI14: 100 − 100 / (1 + average gain / average loss). The backend seeds averages with 14 close-to-close changes (15 bars), then applies Wilder smoothing: (previous average × 13 + current gain or loss) / 14. Flat RSI = 50; no losses = 100; no gains = 0. Guides at 30 / 70 are reference levels, not buy / sell recommendations.
        Backend values use the whole archive for warm-up, including the current bar—not just the visible window. Null values remain gaps (warm-up or unavailable). The browser only plots / formats returned values; it never computes indicators. Basis: provider_close; provider-adjusted prices and an incomplete latest bar can affect interpretation. Switching display or overlays retains selection; a selected date outside a shorter window is remembered while the latest visible bar is shown.
